# dot-nixos

Multi-host, multi-user NixOS flake with decoupled user/host configs, SOPS-based 
secrets management, builtin impermanence, quality of life "just" recipe and 
nix library overlays for common tasks, and sensible defaults for customization

## Architectures

### Philosophy

- Anything that may be declarative, shall be, by all means, declarative
- User-level configuration must be, or attempted to be independent and unaware of 
system-level configuration. This way, a user can be reused on multiple hosts 
- Opinionated by nature, but with sensible defaults and
